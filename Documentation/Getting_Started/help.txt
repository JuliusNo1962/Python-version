From the repository root, create a virtual environment and install dependencies:

Linux:
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
./Testing/Tools/run.sh

Windows (PowerShell):
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\Testing\Tools\run.bat

Build with the single specification at src/main.spec:
.venv/bin/python -m PyInstaller --noconfirm src/main.spec

See ../../README.md for system prerequisites and ../README.md for developer guides.
